# ZeroGen Learning — verbindliche Codex-Regeln

1. `CODEX-MASTERLOOP.md` ist die allein gültige aktuelle Produktspezifikation. Früherer Academy-/Freebuff-/Antigravity-Scope ist aufgehoben.
2. Nur persönlicher Lernfluss: nächsten externen Kurs öffnen → Abschluss erfassen → **echte** optionale Note 0–100 → Fortschritt anzeigen. Maximal drei schlichte Bereiche.
3. KISS/YAGNI: Bestand prüfen, wiederverwenden, kleinste Lösung bauen, unnötigen Code entfernen; weder neue Funktionen noch Abhängigkeiten ohne nachweislichen Bedarf.
4. Eigentümer-Sicherheit, verlässliche Speicherung, Eingabevalidierung, Konfliktanzeige, Barrierefreiheit und Tests **nicht** wegoptimieren.
5. Erst lokale App, dann Firebase Spark (Auth + Realtime Database), dann PWA. Keine kostenpflichtigen APIs/Upgrades und keine automatische Cloud-Bereitstellung.
6. Professionelles, minimalistisches ZeroGen-Design. Keine generischen KI-Dashboards, Marketing-Heroes, Fake-Daten oder Deko-Animationen.
7. Nach jeder Etappe reale Tests ausführen, maximal drei gezielte Fehlerbehebungsversuche pro Blocker. Keine erfundenen Testergebnisse.
8. Keine produktiven Daten löschen, keine bestehenden Nutzerkonten verändern, keine öffentlichen Deployments ohne ausdrückliche Freigabe.
9. Kurz berichten: Geändert · Tests · Ergebnis · Offen. Den Fortschritt in `PROGRESS.md` sichern.
